# Mini-OS-Simulator
Learning and practically understanding OS is hard as although one might understand theory, still it isn’t highly intuitive how the process works in the background.
Due to this invisible nature of OS, some students fail to get the feel of OS working. 
Everyone knows that CPU only does one thing at a time, and how OS juggles the memory. 
But it does that on its own, and to learn from that is hard. We can’t check what happens if system has too less memory or how CPU decides which program to run next.

To solve this and to help students and ourselves to visualize the workings of an OS, we are building this Mini OS simulator.
This is just a simulator that aims to help to understand how OS works by allowing user to change the memory available, which algorithm to use etc., and is not an actual OS kernel.
Using this the user will be exposed to the working of the OS while still abstracting the minor details like how the internal parameters etc. are changed.
Thus they will be able to visualize and understand it better.
